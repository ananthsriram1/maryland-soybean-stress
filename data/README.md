# Data acquisition and expected local paths

This repository is **deposit-ready code**. It intentionally does **not** ship the `data/` inputs in git.
To reproduce the manuscript figures end-to-end, you must populate `data/` with the expected source files.

This document lists, for each required dataset:

- **dataset name**
- **source URL**
- **download / query steps**
- **expected local path(s)** in this repo after download

If you add new inputs or change filenames, update this file so a clean clone remains reproducible.

---

## 1) USDA NASS (yields, acreage, irrigation)

### 1.1 Soybean yield by county (bu/acre)

- **Used by**: multiple figures + stress analyses (county-year yields, district averages).
- **Source**: USDA NASS Quick Stats
- **URL**: `https://quickstats.nass.usda.gov/`
- **Steps (Quick Stats UI)**:
  - Program: **SURVEY**
  - Sector: **CROPS**
  - Group: **FIELD CROPS**
  - Commodity: **SOYBEANS**
  - Data Item: **SOYBEANS - YIELD, MEASURED IN BU / ACRE**
  - Domain: **TOTAL**
  - Geographic Level: **COUNTY**
  - State: **MARYLAND**
  - Years: **1997–2025** (or the full available record; match manuscript scope)
  - Output: **CSV**
- **Expected path**:
  - `data/nass/Soybean_Yield_BU:Acre_By_County.csv`

### 1.2 Soybean acres planted by county

- **Used by**: Figure 10 and supporting context.
- **Source**: USDA NASS Quick Stats
- **URL**: `https://quickstats.nass.usda.gov/`
- **Steps**: same as above, but Data Item:
  - **SOYBEANS - ACRES PLANTED**
- **Expected path**:
  - `data/nass/Soybean_Acres_Planted_By_County.csv`

### 1.3 National soybean yield (for reference lines)

- **Used by**: Figure 4 variants / reference overlays.
- **Source**: USDA NASS Quick Stats (or your existing exported table)
- **URL**: `https://quickstats.nass.usda.gov/`
- **Steps**:
  - Program: **SURVEY**
  - Geo Level: **NATIONAL**
  - Commodity/Data Item: as in 1.1
  - Years: match manuscript
- **Expected path**:
  - `data/NationalAveragesSoybeanAcreageYield.csv`

### 1.4 Irrigated acres harvested by county (census years)

- **Used by**: irrigation vs drought analyses and irrigation overlays.
- **Source**: USDA NASS (Census / Quick Stats export used in this repo)
- **URL**: `https://quickstats.nass.usda.gov/`
- **Expected path**:
  - `data/nass/IrrigatedAcresHarvestedByCounty.csv`

### 1.5 Irrigation vs non-irrigation dataset (repo-preprocessor input)

- **Used by**: `analysis/preprocessing/preprocess_irrigation_census.py`
- **Expected path**:
  - `data/nass/IrrigationvsNonirrigated.csv`

## 2) NOAA / NCEI (precipitation + Palmer indices)

### 2.1 County precipitation (monthly)

- **Used by**: Figure 3 precipitation summaries and precipitation trend scripts.
- **Source**: NOAA/NCEI (county-level precipitation exports used in this repo)
- **Expected directory**:
  - `data/Precipitation_Data_NOAA_97-25/`
- **Expected files**:
  - `data/Precipitation_Data_NOAA_97-25/<County>.csv` (24 Maryland counties)

> The combiner expects the same per-county CSV format used historically in this project
> (see `analysis/preprocessing/combine_precipitation.py` for parsing details).

### 2.2 Palmer drought indices (PDSI / PHDI / PMDI), per county

- **Used by**: drought aggregation and flash drought proxy analyses.
- **Source**: NOAA/NCEI (Palmer drought index exports)
- **Expected directories**:
  - `data/pdsi/`
  - `data/phdi/`
  - `data/pmdi/`
- **Expected files**:
  - `data/{pdsi|phdi|pmdi}/<County>.csv` (per-county CSVs)

The combiner `analysis/preprocessing/combine_palmer_index.py` pivots these into:

- `data/maryland_pdsi_combined_wide.csv`
- `data/maryland_phdi_combined_wide.csv`
- `data/maryland_pmdi_combined_wide.csv`

## 3) Google Earth Engine exports (Sentinel-2 / Landsat 8/9 composites)

### 3.1 10-day soybean NDVI/NDWI county time series (CSV exports)

- **Used by**: Figures 8–9 and the index/differential stress analyses.
- **Generated by**: the GEE editor scripts (to be moved to top-level `GEE_Scripts/` in Phase 4 Round 3).
- **Expected directory**:
  - `data/MD_SOYBEAN_10DAY/`
- **Expected files**:
  - `data/MD_SOYBEAN_10DAY/MD_Soybean_10Day_TimeSeries_<YYYY>.csv`

Then run:

```bash
python -m analysis.preprocessing.preprocess_10day_indices
```

to produce the canonical analysis inputs:

- `data/maryland_soybean_10day_timeseries_long.csv`
- `data/maryland_soybean_10day_timeseries_wide.csv`
- `data/maryland_soybean_10day_timeseries_wide_imputed.csv`

## 4) Soil composition (band-5 soybean mask) and soil water content

### 4.1 Processed band-5 soil composition tables (inputs to Figure 2 generator)

- **Used by**: `analysis/figures/figure02_soil_district_heatmap_variants.py`
- **Expected paths**:
  - `data/processed_band5/maryland_soil_composition_processed_band5_2020band5.csv`

These are created by the soil preprocessing path (see `analysis/preprocessing/preprocess_soil_composition.py`)
from your canonical band-5 soil inputs.

### 4.2 Soil water content table

- **Used by**: `analysis/stress_analysis/longitudinal_10day_index_analysis.py`
- **Expected path**:
  - `data/maryland_only_soil_water_content_FINAL.csv`

Reference values used in interpretation:

- **Klopp, H., Bly, A. (2024)**. “How soil holds water.” SDSU Extension. `https://extension.sdstate.edu/how-soil-holds-water`

## 5) What a fresh clone needs to run

At minimum, a clean clone must have enough `data/` inputs to run:

```bash
python -m analysis.figures.regenerate_manuscript_figures
```

If this fails due to missing `data/` files, the error message should point at the missing path(s).
When you discover missing-file friction, update this `data/README.md` with the correct acquisition steps.
